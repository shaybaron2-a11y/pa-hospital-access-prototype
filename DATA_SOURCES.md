# Data sources and validation plan

## Current official snapshot

The dashboard uses a dated local snapshot generated by `scripts/fetch_official_data.py`. The latest snapshot was retrieved on **2026-08-22** and contains:

- 67 Pennsylvania counties from Census TIGERweb;
- ACS population, age 65+, poverty, and uninsured estimates;
- 109 CMS records classified as `Acute Care Hospitals` whose addresses were successfully geocoded;
- derived county-centroid distances, hospital counts, hospital rates, and priority scores.

The page loads `data/pa_access_official.js` so GitHub Pages can work without live API calls. The same records are available as `data/pa_county_access_official.csv` and `data/pa_hospitals_official.csv`.

## Source registry

| Data | Provider | Use | Source |
|---|---|---|---|
| ACS estimates | U.S. Census Bureau / ACS | Population, age, poverty, insurance | <https://api.census.gov/data/2024/acs/> |
| Hospital directory | Centers for Medicare & Medicaid Services | Facility, county, hospital type, emergency-services field | <https://data.cms.gov/provider-data/dataset/xubh-q36u> |
| County boundaries | U.S. Census Bureau TIGERweb | County GEOID and boundary centroid | <https://tigerweb.geo.census.gov/arcgis/rest/services/TIGERweb/State_County/MapServer/1> |
| Address coordinates | U.S. Census Bureau Census Geocoder | Hospital latitude and longitude from CMS address | <https://geocoding.geo.census.gov/geocoder/> |

## Provenance rules

Every county row carries `source_acs_url`, `source_boundary_url`, `source_hospital_count_url`, `source_nearest_url`, `source_rate_url`, and `retrieved_at`. Hospital rows carry CMS and Census Geocoder source fields. ACS release is retained per county because the mirror may return a 1-year release for larger counties and a 5-year release for smaller counties.

The Census API was unavailable without a key in the build environment, so the script reads the same ACS tables through the Census Reporter API mirror and retains the canonical Census API URL plus the exact retrieval URL. For production research, use a Census API key or download the official ACS summary files directly and compare results.

## Derived metrics and limitations

1. The county reference point is a planar centroid of the Census TIGERweb county polygon.
2. Hospital coordinates are geocoded from CMS addresses using the Census Geocoder.
3. `nearest` is great-circle distance from the county centroid to the nearest geocoded CMS acute-care hospital. It is **not** a road distance or travel time.
4. `rate` is CMS acute-care hospital count divided by ACS population, multiplied by 100,000. It is not a bed-capacity or specialty-care measure.
5. `density_class` is a transparent population threshold proxy used for filtering, not an official rurality classification.
6. The priority score is an exploratory teaching model. It must not be interpreted as a clinical, EMS, or public-policy recommendation.

## Recommended next validation

- Use official ACS files or a registered Census API key and document the exact table vintages.
- Join county/tract geometries using stable GEOIDs rather than county names.
- Add CMS facility type, emergency availability, beds, and specialty services.
- Replace centroid distance with population-weighted tract/block-group origins.
- Calculate 15-, 30-, 45-, and 60-minute road-network travel times.
- Compare results with EMS service areas, hospital referral regions, and sensitivity analyses using alternative weights.
