# Pennsylvania Hospital Access Prototype

Interactive display page for the Pennsylvania hospital access prototype.

## Open the display

- GitHub Pages: `https://health.shaybaron.com`
- Local file: open `index.html`
- Interactive map file: `figures/interactive_hospital_access_map.html`

## Project files

- `index.html`: main display page.
- `figures/interactive_hospital_access_map.html`: interactive map display.
- `data/`: prototype data used by the displays.
- `scripts/build_project.py`: script for rebuilding the display assets.
- `one_page_project_pitch.md`: research summary.
- `DATA_SOURCES.md`: data-source notes.
